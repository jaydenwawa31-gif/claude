    Git rescue kit

    The seven mistakes everyone makes, and the commands that undo them.

    My last commit message is wrong

    Rewrites the message of the latest commit. Only do this before you push.

    git commit --amend -m "Better message"
    I want to undo my last commit but keep my changes

    The commit disappears, your files stay exactly as they are, and the changes are staged again.

    git reset --soft HEAD~1
    I committed to the wrong branch

    Move the commit to a new branch, then reset the old one. Replace main with the branch you were on.

    git switch -c the-right-branch
git switch main
git reset --hard origin/main

    The last line discards unpushed commits on main. They’re safe on the new branch.

    I want to throw away my changes to one file

    Resets the file to the last committed version. There is no undo for this one.

    git restore path/to/file
    I deleted a branch I still needed

    Find the last commit the branch pointed to in the reflog, then recreate the branch there.

    git reflog
git switch -c my-branch <sha-from-reflog>
    I already pushed a bad commit

    Don’t rewrite shared history. Add a new commit that reverses the bad one.

    git revert <sha>
git push
    I pushed a password or API key

    Revoke and replace the secret first. Deleting the commit doesn’t help, because anyone may already have copied it.

    Then remove it from history with git filter-repo and force-push, and ask collaborators to re-clone.

    git filter-repo --replace-text secrets.txt
